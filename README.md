## ✨ About

**Dananz** is a pet project — a handcrafted static website focused on clean markup, expressive styling, and a smooth developer experience. No frameworks, no bloat. Just well-structured HTML, modular SCSS, and a sprinkle of JavaScript where it counts.

---

## 🛠 Tech Stack

| Tool | Role |
|------|------|
| **HTML5** | Semantic structure & layout |
| **SCSS** | Modular, maintainable styling |
| **JavaScript** | Lightweight interactivity |
| **Vite** | Dev server & build tool |
| **gh-pages** | Deployment to GitHub Pages |

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+ recommended)

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/Lackevil/Dananz.git
cd Dananz

# 2. Install dependencies
npm install

# 3. Start the dev server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

---

## 📦 Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start local development server with HMR |
| `npm run build` | Build for production into `/dist` |
| `npm run preview` | Preview the production build locally |
| `npm run deploy` | Deploy `/dist` to GitHub Pages |
